# [Feature] Playwright E2E テスト

## 背景
主要フローを自動化して検証する（spec.md §8、AGENTS.md のルール）。

## 内容
- Playwright + TypeScript でテストを作成する
- カバレッジ対象:
  - 追加（Enter / ボタン / 空入力拒否 / 200 文字制限）
  - 完了 / 未完了の切り替えと永続化
  - 削除
  - 編集（保存 / キャンセル）
  - フィルタ切替
  - 完了済み一括削除
  - ページ再読み込み後のデータ保持
  - ダークモードでの表示

## 受け入れ基準
- [ ] `npm run test:e2e` で全テストが通る
- [ ] 主要フロー（追加 / 完了 / 削除）はテストで検証済み
