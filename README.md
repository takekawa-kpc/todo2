# TODOアプリ

ローカル（localStorage）だけで動作するシンプルな ToDo アプリです。バックエンドは不要で、ブラウザ内だけでデータの保存・表示を行います。

## 使い方（チュートリアル）

アプリを起動すると、次の 3 つのエリアで構成された画面が表示されます。

```
┌──────────────────────────────┐
│ ToDo                         │  ← ヘッダー
│ [ 新しい ToDo を入力      ] [追加] │  ← 追加フォーム
│      0/200                    │  ← 文字数カウンター
│ ┌──────────────────────────┐ │
│ │ ☐ 買い物          9/23 14:02 [削除] │  ← ToDo 一覧
│ │ ☐ メール返信      9/23 14:01 [削除] │ │
│ └──────────────────────────┘ │
│ 残り 2 件                     │  ← フッター
└──────────────────────────────┘
```

### 1. ToDo を追加する

1. 入力欄に ToDo の内容を打ち込みます（例: `買い物`）。
2. **`Enter` キー**を押すか、**「追加」ボタン**をクリックすると、一覧の**先頭**に追加されます。
3. 追加後は入力欄が自動的に空になり、次の入力にフォーカスが戻ります。

**制約・ルール**

- 空文字・空白のみの入力は追加できません（「追加」ボタンも無効になります）。
- 1 項目あたり **最大 200 文字**です。右下のカウンター（`12/200`）で残り字数を確認できます。

### 2. ToDo を確認する

- 各項目には **本文** と **作成日時**（例: `2026/09/23 14:02`）が表示されます。
- 新しい順（先頭追加）に並べ替えられます。
- 一覧が空の場合は「**ToDo ありません**」と表示されます。
- 画面下部の「**残り N 件**」で未完了の件数が分かります。

### 3. ToDo を削除する

- 項目右側の**「削除」ボタン**をクリックすると、その項目だけが一覧から消えます。
- 削除は即座に保存され、ページを再読み込みしても復活しません。

### 4. データは自動保存されます

- 追加・削除のたびに **localStorage** に自動保存されるため、ブラウザを閉じても次回開いたときに同じ内容が表示されます。
- 保存先に**壊れたデータ（不正な JSON）**がある場合は、そのデータをバックアップ（`todo-app.items.bak`）して安全な空リストから開始します。クラッシュはしません。
- 保存に失敗した（容量超過など）場合はエラーメッセージを表示し、**既存データは失われません**。

### 5. データを全部リセットしたい場合

ブラウザの DevTools（`F12` → コンソール）で次のコマンドを実行すると、保存データを消去して空の状態に戻せます。

```js
localStorage.removeItem('todo-app.items')
localStorage.removeItem('todo-app.items.bak')
location.reload()
```

## 開発

### 必要なもの

- Node.js（推奨: 20 以上）
- npm

### セットアップ

```bash
npm install
```

### コマンド

| コマンド | 説明 |
|----------|------|
| `npm run dev` | 開発サーバーを起動（http://localhost:5173/todo2/） |
| `npm run build` | 型チェックと本番ビルド（`dist/` に出力） |
| `npm run preview` | ビルド結果をローカルで確認 |
| `npm run test:e2e` | Playwright E2E テストを実行（開発サーバーは自動起動） |
| `npm run type-check` | TypeScript の型チェックのみ |

### 技術スタック

- [React](https://react.dev/) + [TypeScript](https://www.typescriptlang.org/)
- [Vite](https://vite.dev/)
- [Tailwind CSS](https://tailwindcss.com/)（ダークモード対応）
- [Playwright](https://playwright.dev/)（E2E テスト）
