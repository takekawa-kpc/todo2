# [Feature] ToDo の追加

**状態:** 完了

## 背景
ToDo アプリの基本機能として、ToDo を追加できることが必要（spec.md §4.1）。

## 内容
- 入力欄にテキストを入力し、Enter キーまたは「追加」ボタンで追加できる
- 空文字・空白のみの入力は無視される
- 入力は最大 200 文字を制限する
- 追加後は入力欄が空になり、フォーカスが維持される
- 追加直後に localStorage に保存される

## 受け入れ基準
- [ ] テキストを入力して Enter キーで追加できる
- [ ] 「追加」ボタンでも追加できる
- [ ] 空・空白のみでは追加できない
- [ ] 200 文字を超える入力は制限される
- [ ] 追加後、入力欄が空になりフォーカスが維持される
