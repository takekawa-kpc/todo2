# [Feature] 完了 / 未完了の切り替え

**状態:** 未着手

## 背景
ToDo の完了状態を切り替えられることが必要（spec.md §4.3）。

## 内容
- チェックボックスで完了 / 未完了を切り替えられる
- 完了した項目は視覚的に区別される（取り消し線・色薄め）
- 切り替えは即座に localStorage に反映される
- 切り替え時に軽いアニメーションがある

## 受け入れ基準
- [ ] チェックボックスで状態を切り替えられる
- [ ] 完了項目は視覚的に区別できる
- [ ] 切り替えは再読み込み後も保持される
