# [Feature] ToDo の編集

## 背景
追加した ToDo の本文を後から修正できることが必要（spec.md §4.5）。

## 内容
- 項目の本文をインライン編集（または編集モーダル）で変更できる
- Enter または保存ボタンで確定、Escape でキャンセル
- 空文字・空白のみの編集は適用されない
- 編集は即座に localStorage に反映される（`updatedAt` も更新）

## 受け入れ基準
- [ ] 本文を編集して保存できる
- [ ] Escape でキャンセルでき、原文が維持される
- [ ] 空文字列への編集はされない
- [ ] 編集内容は再読み込み後も保持される
