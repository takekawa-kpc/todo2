# [Feature] UI / デザイン実装

## 背景
モダンでミニマルな見た目と快適な操作性（spec.md §6）。

## 内容
- Tailwind CSS で実装し、中央寄せ 1 カラムレイアウト（最大幅 640px 程度）
- ダークモード対応（OS/ブラウザ設定に追随、または手動切替）
- 追加・削除・完了切り替え時の軽いアニメーション（fade / slide）
- 主要操作はキーボードのみで完結する（Tab / Enter / Escape）
- 十分なコントラスト比、フォーカスリング、aria 属性

## 受け入れ基準
- [ ] ライト / ダーク両モードで利用可能
- [ ] 主要操作がキーボードのみで完結する
- [ ] 追加・削除・完了切替にアニメーションがある
- [ ] スクリーンリーダーで主要操作を理解できる
